# Lexicon Launchpad

Create a landing page for my startup called Lexicon which is focused on bridging the gap between having a seal of biliteracy or colloquial/working proficiency between having a professional working proficiency specifically for technical fields like medical terminology or business fields like the economics/finance terminology that would be used day to day. We are currently focusing on mandarin, spanish, and hindi. We want our branding to be the colors butter yellow hex code is #16324B and navy blue hex code is #F3EDDD.
